# 路线图草案

> 状态：所有阶段均未实现，待人工审查与拆分。验收项用于定义未来证据，不是当前完成声明。

| 阶段 | 目标 | 可衡量的未来验收条件 |
| --- | --- | --- |
| B0 | 蓝图与来源边界 | 文档说明系统边界、许可、风险与非实现状态；结构检查通过 |
| B1 | 契约与回放基础 | 三类消息具备版本和关联 ID；记录可重放的受限事件样本；拒绝未知 kind/旧 epoch |
| B2 | 只读世界桥接 | 可把受授权世界的观察转成 NDJSON；不发送变更世界的动作；不可信文本与事实分开 |
| B3 | 有界行动与取消 | 每 actor 至多一个变更行动；超时、取消、断连产生明确终态；`unknown` 不自动重试 |
| B4 | 认知与记忆 | 认知只经受限技能提出计划；记忆来源可追溯；不向模型开放任意命令执行 |
| B5 | 多 actor 与评估 | 多 actor 场景可复现；队列压力、陈旧 epoch、取消竞态和权限拒绝有测试证据 |

## 阶段依赖

先稳定 B1 的消息含义，再引入 B2 的只读端口。B3 依赖 B1/B2 的回执和观察语义；B4、B5 不应绕过 B3 的授权、队列和审计边界。

每个阶段开始前应由人工确认行动白名单、目标世界、风险边界和验收数据。具体优先级可调整，但不得把蓝图描述视为实现承诺。
