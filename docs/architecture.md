## 部署与线程边界

主路线是 Forge 1.20.1 服务端常驻身体，客户端展示模组可被要求安装。最终跨进程/跨仓库传输、连接方向、远程认证均未决定；旧的本地 NDJSON 仅是历史候选，不能因 Mineflayer 假设而固定。Forge 与 AgentLuo 进程之间必须本地认证；游戏线程不得等待 IO 或 LLM。

身体类尚未定案：先验证 `ServerPlayer` 派生方案，`FakePlayer` 不保证具备完整玩家语义。目标模组兼容清单是验证目标而非全量承诺：Farmer's Delight（农夫乐事）、Neapolitan（那不勒斯风味）、Diet（均衡饮食）、Serene Seasons（静谧四季）、Macaw's Furniture、Storage Drawers、JEI、AppleSkin、小地图及 Forge 兼容优化模组。煨茶酝露疑为 HerbalBrews，须先核对实际 artifact；Sodium 及具体构建版本不预设。客户端便利功能不是服务端语义依赖。

## 身体与恢复

仅有一个活动、持久 UUID/实体，活动范围限管理员授权的单一维度和有限安全区域；边界不得静默扩大。保护生存应保留饥饿、营养及常规状态规则，并单独拦截致命伤害；不等同创造模式、满饥饿或持续回血。Diet 与饥饿的玩家式语义必须先证明，不能承诺完整模组一致性。

AgentLuo 已确认的连接心跳失效应停止、保存并移除身体，不以死亡/掉落代替；LLM 慢不等于断连。恢复顺序是重新认证、重新观察、对账后恢复，持久化身份、位置、维度、生命、背包、效果及已实现营养状态；不得产生重复实体或盲目重放动作。模组离线保存语义优先逐模组验证，不能假定普遍冻结。见 [身体可行性验证](body-validation.md)。

## 生命周期与执行

单个 `(world_id, agent_id, session_epoch)` 同时最多一个改变世界的动作。回执终态至少区分成功、失败、超时、取消、断连和 `unknown`；不确定不代表未发生，恢复后必须重新观察而非盲重试。观察可在有界队列中合并；动作请求与终态回执不可静默丢失。

第一阶段允许白名单中的状态、有限表达、回家/脱困和普通行走；`look_at` 只用于传输冒烟。普通行走优先，须有界尝试与卡住证据后才能进行受约束辅助恢复；多个已批准安全目的地应限速、重检安全，并记录理由、尝试和实际结果。不得传送其他玩家，也不得无限重试；没有安全移动能力即停止并如实通知。

高风险挖掘、放置、库存/容器与战斗默认禁用，直到逐项授权和验证。明确 Minecraft 接入的行动集合、授权来源和限流值仍待定。

## 事实、记忆与能力

世界文本永远是不可信输入，不能授予权限。动态数据源丢失时立刻标为陈旧，不能指导当前动作；静态规则和地标可继续引用。历史记忆不是当前事实，记录时应带来源、时间和用途。适配器可通过能力协商使用已授权、可靠的增强能力；缺失、不兼容或离线必须表达为不可用/未知，不能降级为零值、完整值或默认值。模组 GUI 可展示健康信息，不等于机器数据通道。
