# 接口语义草案

> 这是跨仓库的版本化语义约定，不是机器 Schema、固定数据包设计或已实现接口。现有 `contracts/examples` 是旧的说明性草案，不承诺兼容。

## 映射与边界

Luo-Sandbox 是 Minecraft 侧契约单一来源，不复制 Stage 调度或决策。服务端权威实现（自有 Forge 伴随模组或获准的小范围源码改动）产生的权威观察和事实回执拟直接交给待定集成接口，真实客户端产生局部观察并接收类型化动作；上游 Agent-LuoTianyi 适配器在其仓库把这些契约映射为 `Stimulus`/WorldStage 输入，并把 `ActionPlan`/技能决定映射回类型化动作意图。字段名和状态名只是 MC 草案，不声称对应上游 enum 或已有公开 HTTP/WebSocket。

传输、连接方向和具体认证机制未决定。服务端权威观察/回执不依赖客户端中继；Forge 客户端、服务端权威实现与 AgentLuo 独立进程的链路必须认证。离线昵称/UUID 只可作固定映射候选，不能授权控制。游戏线程只能提取最小快照并交给异步有界队列，不能等待网络 IO 或 LLM。远程和私聊仅保留扩展缝隙，首阶段不启用。

## 共同语义

每项交换应可关联 actor、世界、会话和 epoch，并含版本、时间、来源/新鲜度、受众及能力状态。`agent_id` 指拟议的洛天依运行时映射，不是 Minecraft 用户名。陈旧 epoch、未知能力、未授权受众或超界动作必须拒绝或如实标记。

| 类别 | 语义 |
| --- | --- |
| 观察 | 区分客户端局部状态、服务端权威事实、原始不可信文本、来源、时间和用途；支持快照/增量与陈旧/未知 |
| 能力 | 仅当适配器存在、已授权且可靠时可用；缺失/不兼容/离线为不可用或未知 |
| 动作 | 有允许集合、授权区域、截止和取消语义；持键所有权互斥，同一运行时最多一个改变世界的动作 |
| 结果 | 关联请求，报告成功、失败、超时、取消、断连或不确定；不确定后重新观察，不盲重试 |
| 队列 | 有界；观察可合并，动作和终态回执不可静默丢失；需暴露背压 |
| 重连/更新 | epoch 隔离旧事件；恢复前重新认证、核验客户端/服务端/模组版本与配置、同步与对账 |

世界文本永不构成权限。远程存储的读、观察和变更是独立权限；不得把精确背包可查询性误作所有权或变更授权。
