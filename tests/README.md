# 验证范围草案

> 当前可执行检查包括仓库结构脚本及最小 Forge 骨架的非游戏元数据测试；没有真实客户端或服务器 runtime 测试。

未来验证应覆盖（当前没有实现测试套件）：

- 真实客户端与服务端伴随模组的控制绑定、输入释放、Diet/饥饿可行性及保护生存语义
- AgentLuo `Stimulus`/WorldStage 与 `ActionPlan`/技能的实际映射；不假定已有公开端点
- 身份绑定、来源/受众过滤、动态源失效、公开记忆与私有数据不泄露
- 正常/紧急停止、断连保存/移除、重认证/重观察/对账恢复与不盲重试
- 动作白名单、行走卡住证据、辅助恢复限制、背压与如实回执
- 能力缺失/不兼容/离线时的未知或不可用降级

先完成 2 小时、3–5 位受邀者的目标服务器验证，能重复覆盖隐私、认证、停止、恢复、降级与如实反馈后，才考虑扩展白名单；不得据此自动公开上线或启用无人值守生产运行。
