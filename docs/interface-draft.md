# 接口语义草案

> 这是跨仓库的版本化语义约定，不是机器 Schema、固定数据包设计或已实现接口。现有 `contracts/examples` 是旧的说明性草案，不承诺兼容。

## 映射与边界

Luo-Sandbox 是契约单一来源，经 AgentLuo 适配器映射到上游能力；不复制 Stage 调度或决策。输入观察拟映射为 `Stimulus`/WorldStage，输出由 `ActionPlan`/技能决定映射为类型化 Minecraft 动作，再以回执结算。字段名和状态名只是 MC 草案，不声称对应上游 enum 或已有公开 HTTP/WebSocket。

传输、连接方向和远程认证未决定。Forge 与 AgentLuo 独立进程的本地链路必须认证；远程和私聊仅保留扩展缝隙，首阶段不启用。游戏线程不得等待网络 IO 或 LLM。

## 共同语义

每项交换应可关联 actor、世界、会话和 epoch，并含版本、时间、来源/新鲜度、受众及能力状态。`agent_id` 指拟议的洛天依运行时映射，不是 Minecraft 用户名。陈旧 epoch、未知能力、未授权受众或超界动作必须拒绝或如实标记。

| 类别 | 语义 |
| --- | --- |
| 观察 | 区分事实、原始不可信文本、来源、时间和用途；支持快照/增量与陈旧/未知 |
| 能力 | 仅当适配器存在、已授权且可靠时可用；缺失/不兼容/离线为不可用或未知 |
| 动作 | 有允许集合、授权区域、截止和取消语义；同一运行时最多一个改变世界的动作 |
| 结果 | 关联请求，报告成功、失败、超时、取消、断连或不确定；不确定后重新观察，不盲重试 |
| 队列 | 有界；观察可合并，动作和终态回执不可静默丢失；需暴露背压 |
| 重连 | epoch 隔离旧事件；恢复前重新认证、同步与对账 |

世界文本永不构成权限。远程存储的读、观察和变更是独立权限；不得把精确背包可查询性误作所有权或变更授权。
