# 路线图草案

> 状态：所有阶段均未实现，待人工审查与拆分。验收项用于定义未来证据，不是当前完成声明。

| 阶段 | 目标 | 可衡量的未来验收条件 |
| --- | --- | --- |
| B0 | 集成蓝图与来源边界 | 文档说明 AgentLuo/本仓库职责、许可、风险和非实现状态；结构检查通过 |
| B1 | 跨仓库契约验证 | 经上游代码审查的映射明确三类消息、关联 ID 与版本；拒绝未知 kind/旧 epoch；不假定已有端点 |
| B2 | 只读 AgentLuo 集成 | 受授权 Minecraft 观察可作为上游 `Stimulus`/WorldStage 输入；不可信文本与事实分开；不发送变更动作 |
| B3 | 上游驱动的有界行动环 | 上游 `ActionPlan`/技能决定映射为类型化行动；每个洛天依运行时至多一个变更行动；取消、断连和 `unknown` 无盲重试 |
| B4 | 持久生活与记忆一致性 | 经过验证的世界状态可反馈上游记忆/后续决策；受约束地覆盖移动、探索、聊天、材料与日常习惯 |
| B5 | 扩展世界互动 | 在逐项授权、审计和恢复验证后扩展交互；挖掘、放置、库存等高风险动作默认仍禁用，直至单独批准 |

## 阶段依赖

先稳定 B1 的上游映射与消息含义，再引入 B2 的只读接入。B3 依赖 B1/B2 的回执和观察语义；B4、B5 不应绕过上游 WorldStage 的调度所有权及 B3 的授权、队列和审计边界。

每个阶段开始前应由人工确认行动白名单、目标世界、风险边界和验收数据。具体优先级可调整，但不得把蓝图描述视为实现承诺。
